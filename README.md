# Loomwyrd of Echo

**Every path leaves an echo.**

Loomwyrd of Echo is an independent game project building an evolving game universe. It brings together elements of RPG, MUD, roguelite, and strategy systems, with a long-term vision centered on exploration, character progression, discoveries, and player interaction.

The project is under active development. Its concepts, systems, and public documentation are being developed iteratively.

## Explore the project

- [Concept](project/CONCEPT.md) — the project's public concept, gameplay direction, and long-term vision.
- [About](project/ABOUT.md) — an overview of the project, its development, and this documentation.

## Development status

Loomwyrd of Echo is an ongoing project. Not all planned features are currently available or implemented. Public materials distinguish the project's current state from ideas and long-term development directions.

More detailed information about the current development phase, progress, and roadmap will be added as it is reviewed and confirmed for public release.

## Documentation

This repository contains selected public information about Loomwyrd of Echo. It is not the complete internal project archive and does not disclose all worldbuilding materials, game systems, or technical implementation details.

Documentation is expected to evolve alongside the project. Pages may be expanded, clarified, or revised as the game world is recovered and organized and as development progresses.

## Русская версия

**Каждый путь оставляет отголосок.**

Loomwyrd of Echo — независимый игровой проект, создающий развивающуюся игровую вселенную. Он объединяет элементы RPG, MUD, roguelite и стратегических систем. Долгосрочное направление проекта строится вокруг исследования, развития персонажа, открытий и взаимодействия игроков.
